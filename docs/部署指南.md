# 部署指南：让同事也能用上这个检索

> 本文所有命令都在**项目根目录**（也就是 `README.md` 所在的那一层）执行。

## 0. 先说结论

你猜得对：**PDF 原件一个都不用传**。前端只调 `/api/*`，检索结果里的"页码"是纯文本，
站上没有任何指向 PDF 的链接。要部署的只有三样：

| 要传的东西 | 大小 | 说明 |
| --- | --- | --- |
| `src/` | 约 250 KB | 服务端代码（`server.py` `search.py` `extract.py` `normalize.py` + `webui/index.html`） |
| `data/queries.db` | 420 MB | 全部索引，**唯一的"大件"** |
| Python 环境 | — | 只要 `fastapi` + `uvicorn` 两个包 |

顺便说一句：**免费、能常开、还能从国内稳定访问的 Python 主机，实际不存在**（§4 有我逐个
实测的结果）。所以这里给三条路，按"今天能不能用上"排序：

- **方案 A**：你自己的电脑当服务器 + Cloudflare 隧道。0 元、0 注册，**今天就能用**。
- **方案 B**：方案 A 加一个自己的域名（`.cn` 首年 38 元/年，`.com` 85 元/年），网址固定下来。
- **方案 C**：真·常开，需要一台服务器。

## 1. 方案 A：电脑当服务器，公网隧道（免费，今天就能用）

### 用法

1. 双击根目录的 **`公网访问.bat`**。
2. 第一次运行会自动下载 `cloudflared`（约 53 MB，实测 ~150 KB/s，等 5~10 分钟），之后就秒起。
3. 窗口里会打出这样一段：

```
  ================================================================
   网站已经开好，把下面两行发给同事就行

     网址：https://print-performs-metric-charming.trycloudflare.com
     口令：wenxun / wenxun2026

   这个窗口一关，网站就下线；网址每次重启都会变。
  ================================================================
```

   网址会自动进剪贴板，也写在 `tools/public_url.txt` 里。
4. 把这两行发到群里，同事点开、输入口令就能用。

### 我已经实测过

不是"应该可以"，是真的跑通了、并且从公网地址请求过：

| 请求 | 结果 |
| --- | --- |
| `GET /` | 200，33 336 B，1.58 s |
| `GET /api/stats` | 200，52 369 B，1.32 s |
| `POST /api/search`（"存货跌价准备计提是否充分"，限创业板） | 200，**0.97 s**，首条是尚水智能（0.838） |

### 要注意的四件事

1. **网页靠这个窗口活着。** 窗口关了、电脑睡眠或关机，网站就下线。建议把电源设置里的
   "睡眠"改成"从不"，不然午休回来同事就打不开了。
2. **网址每次重启都会变**（Cloudflare 免费快速隧道就是这样）。想固定住，见方案 B。
3. **口令在 `公网访问.bat` 第 11 行**：`set "AUTH=wenxun:wenxun2026"`，
   改成你要的"用户名:密码"；写成 `set "AUTH="` 就是不要口令（不建议）。
   这一层是 HTTP Basic 认证，浏览器弹一次框，之后前端所有 `fetch` 自动带上，
   所以网页代码一行都没改。
4. **数据不出这台电脑。** 隧道只是把本机 `127.0.0.1:8765` 借一个公网域名，
   数据库和 PDF 全留在本地，Cloudflare 只是转发 HTTPS 请求和 JSON 响应。

## 2. 方案 B：把网址固定下来（域名几十块/年，其余免费）

### 2.0 先纠正一个误解：买了域名 ≠ 别人能访问

域名只是一张"门牌"。完整链路是：

```
同事的浏览器  ->  Cloudflare（你的域名解析到这里）  ->  加密隧道  ->  你的电脑:8765
```

所以要四件事：**① 买域名 → ② 把域名交给 Cloudflare 托管 → ③ 建隧道把域名绑上去 → ④ 你的电脑开着**。
②③ 里除了"改 NS"和"在浏览器点一次 Authorize"，剩下的我已经写成脚本了。

### 2.1 买域名（5~10 分钟，要实名）

推荐 **阿里云**（中文界面、支付宝、实名认证一条龙）。腾讯云/华为云也一样。

1. 打开 <https://wanwang.aliyun.com>，登录（没有就注册，可以支付宝扫码）。
2. 搜索框里输入想要的名字（比如 `wenxunhui`），看各个后缀的价格。
3. 加入清单 → 选 **1 年** → 结算。
4. 按提示做**实名认证**（个人：身份证正反面 + 人脸识别）。审核几分钟到两小时，
   **没通过之前域名会被 hold，是正常的**。

选哪个后缀（我 2026-10-17 用 DNS 查过，下面这些当时都还没被注册；价格是阿里云标价，以页面为准）：

| 域名 | 阿里云标价 | 我的看法 |
| --- | --- | --- |
| `wenxunhui.cn` | 首年 **38** 元，续费 42 元/年 | **性价比首选**。`.cn` 是主流后缀，公司网关和微信都不会把它当垃圾域名拦 |
| `wenxunhui.com` | 首年 85 元，续费 95 元/年 | 最"正统"，但比 `.cn` 三年多花约 150 元 |
| `wenxun.top` / `wenxun.xyz` | 首年可能几块到几十 | 最便宜。但这类后缀有些公司网关和微信会当垃圾域名拦掉——别拿同事当测试 |
| `wenxunbang.com` | 首年 60~90 元 | 备选（"问询帮"） |

> 我的建议：买 `.cn`。省一半多，而且不会被网关当垃圾域名拦。
> 页面上那个"组合购买优惠（`.com` + `.icu` + `.shop` + `.fun`）"别买，另外三个后缀对你没用。
>
> 另外：**如果你们公司自己已经有域名、而且归 IT 管**，可以问一句能不能给个
> `wenxun.公司域名` 的子域名。注意这条路只有在"那个域名本来就托管在 Cloudflare"时才通——
> 隧道要求 DNS 由 Cloudflare 管着，公司自建 DNS 一般接不了。

另外注意：

- 域名是**按年续费**的，续费价通常比首年贵，结算页面会写清楚。
- 结算时别买搭售的"云服务器""企业邮箱"。**SSL 证书也不用买**——HTTPS 由 Cloudflare 免费提供。

### 2.1b 买域名贵，那租台服务器是不是更划算？

不是，而且差距不小。先把两件事分清楚：

- **服务器**解决的是"**我的电脑得一直开着**"；
- **域名**解决的是"**网址固定、好记、能上 HTTPS**"。

这两件不冲突，也不是二选一——**你现在已经有一台"服务器"了，就是你这台电脑**。
而且注意：租了服务器照样得有域名，才能给同事一个 `https://` 的地址；
直接用 `http://123.45.67.89:8765` 的话，浏览器会标"不安全"，同事第一眼就不敢点。

三年账（价格以各家页面为准，但量级是这样）：

| 走法 | 首年 | 续费/年 | 三年合计 | 额外要付的代价 |
| --- | --- | --- | --- | --- |
| 现状（临时网址） | 0 | 0 | **0** | 网址每次都变 |
| 域名 `.cn` | 38 | 42 | **约 122** | 自己的电脑要开着 |
| 域名 `.com` | 85 | 95 | 约 275 | 自己的电脑要开着 |
| 大陆轻量服务器 | 69~99 | **300~600** | 700 起 | **要 ICP 备案**：2~4 周，且个人主体备案做"金融信息检索"大概率过不了，得走公司主体 |
| 香港/海外轻量服务器 | 200~300 | 200~300 | 600~900 | 不用备案；但 420 MB 数据库要上传，以后运维都归你 |

两个容易忽略的点：

1. **"69/99" 是首年促销价**，续费通常翻三到六倍，下单页往下拉能看到续费价。
2. **大陆服务器的 80/443 必须备案才给解析**，这一步是纯小白最容易卡死的地方：
   要域名实名、要服务器买够三个月、要拍照/视频核验、管局审核 2~4 周。
   而这个网站，个人备案基本过不去（内容属于企业/金融类）。

所以结论：**嫌 85 贵，就换 `.cn`（38），别换服务器。**
真正值得上服务器的理由只有一个——"我不想让电脑一直开着"。

### 2.2 把域名交给 Cloudflare 托管（10 分钟 + 等生效）

Cloudflare 的隧道只能用在"它自己管解析"的域名上，所以要把域名的 NS 改过去。

1. 打开 <https://dash.cloudflare.com/sign-up>，邮箱注册（免费，不要信用卡）。
2. 登录后点 **Add a site**，输入你的域名（只输 `wenxunhui.com`，不带 www、不带 http）→ Continue。
3. 计划选 **Free** → Continue。
4. 它扫一遍现有解析记录，直接 Continue / Save。
5. 最后给你**两个 NS 地址**，长得像：

   ```
   alina.ns.cloudflare.com
   bob.ns.cloudflare.com
   ```

   **把这两行复制下来**（这一步的页面标题是 *Change your nameservers*）。

6. 回阿里云改 NS：控制台 → **域名** → 你的域名 → **管理** → 左侧 **DNS 修改**
   （有的版本叫"修改 DNS 服务器"）→ 选 **自定义 DNS** → 填那两个地址 → 保存。

7. 等。通常 **10 分钟 ~ 2 小时**，最多 24 小时。回到 Cloudflare 域名概览页，状态从
   *Pending Nameserver Update* 变成 **Active** 就成了；页面上还有个
   **Check nameservers now** 按钮可以手动催一下。

> Cloudflare 变成 Active 时会给你发邮件，标题大概是 "… is now active on Cloudflare"。

### 2.3 跑一次设置（2 分钟，全自动）

**双击 `scripts/固定网址-首次设置.bat`**，它会依次问你 / 做这些：

1. **问域名** → 输入你要用的完整网址。想用根域名就输 `wenxunhui.com`；
   想用 `wenxun.wenxunhui.com` 那种子域名，就把全的输进去。
2. **弹浏览器授权** → 登录 Cloudflare，选中你的域名，点 **Authorize**。
3. 自动建隧道、把域名指到隧道、写好本地配置。
4. 打出你的固定网址。

设置完第一次访问要等 **1~5 分钟**（Cloudflare 在下发证书），期间报 502 / 1033 是正常的，等一会儿刷新。

### 2.4 以后每天

**还是双击 `公网访问.bat`。** 它会自己发现你已经配好了固定网址，改走命名隧道，网址永远不变。

想临时退回随机网址：`.venv\Scripts\python.exe deploy\tunnel.py --quick`

### 2.5 常见问题

| 现象 | 怎么办 |
| --- | --- |
| 设置时浏览器没弹出来 | 窗口里会打印一条链接，复制到浏览器里打开 |
| 报"没拿到授权文件" | 浏览器里没点 Authorize；或者域名还没变 Active |
| 设置完访问报 502 / 1033 | 等 1~5 分钟；还不行就确认 `公网访问.bat` 的窗口开着 |
| 报 530 / 1016 | 域名没指到隧道，重跑 `scripts/固定网址-首次设置.bat --force` |
| 同事打不开 | 你的电脑睡眠了。电源设置里把"睡眠"改成"从不" |
| 想换个域名 | 重跑 `scripts/固定网址-首次设置.bat --force` |
| 换了一台电脑 | 把 `tools/named_tunnel.json` 拷过去，再重跑一次设置（同一条隧道可以多处连） |

**要不要备案？** 技术上不需要——域名解析到的是 Cloudflare 的 IP，不是你家的宽带 IP，也不是大陆服务器。
但"把公司内部系统挂到公网"这件事本身，如果你们公司有规定，该报备还是得报备（前面提过）。

## 3. 方案 C：真·常开（需要一台服务器）

`deploy/` 目录里的东西就是为这一步准备的，任意 Linux 服务器都行（公司内网的机器也算）。

```bash
# 1. 传数据库。二选一：
#    a) 直接传原库：420 MB，境外机器实测上行约 0.5 MB/s → 14 分钟起
scp data/queries.db  user@server:/opt/wenxun/data/
#    b) 先压后传：112 MB，约 4 分钟（本机压只要 15 秒，实测 3.7x）
.venv/Scripts/python.exe deploy/pack_db.py --gz
scp data/queries_pack.db.gz  user@server:/opt/wenxun/data/
ssh user@server "cd /opt/wenxun/data && gunzip -c queries_pack.db.gz > queries.db && rm queries_pack.db.gz"

# 2. 起站
cd /opt/wenxun
AUTH=wenxun:wenxun2026 docker compose -f deploy/docker-compose.yml up -d --build

# 3. 打开 http://服务器IP:8765
```

- 云服务器记得在**安全组**放行 8765；公司内网机器就把网址发同事。
- 不想传库也行：把 `queries.db.gz` 放到任意直链，容器启动时设 `DB_URL` 自己下。
- 镜像里**没有** pdfplumber —— 我把 `extract.py` 里读 PDF 的那句改成了函数内延迟
  导入，服务端只剩 `fastapi` + `uvicorn`，镜像很小、构建很快。
- 服务器从哪来：
  - **Oracle Cloud 永久免费**（ARM 4 核 24 GB，最接近"真免费常开"，但要信用卡验证，注册折腾）；
  - 阿里云/腾讯云新用户特惠轻量服务器，约 99 元/年，最省心；
  - 公司自己的机器/虚拟机，0 元。

## 4. 我实测过的免费方案，以及它们为什么不行

"免费部署一个 Python 网站"这件事，2025 年基本没有馅饼了。下面每一条都是我在你这台
机器上现场测出来的，不是抄的攻略：

| 平台 | 结论 | 依据（实测） |
| --- | --- | --- |
| Hugging Face Spaces | ✗ | 官方文档原文：*"Gradio and Docker Spaces run on compute and require a paid plan to create: PRO for personal accounts"*。免费只剩 Static Space（纯静态，跑不了 Python）。可惜，**它的 CDN 从你这里下载有 8.9 MB/s** |
| Render | ✗ | `https://render.com` 和 `dashboard.render.com` 从你这台机器 **TLS 连接直接失败**，连控制台都打不开 |
| Koyeb | ✗ | Starter（免费）档已对新用户关闭 |
| Zeabur | ✗ | Free 方案不含算力，"最多 1 台**绑定外部服务器**"——还是得有服务器 |
| PythonAnywhere | ✗ | 免费档磁盘总共 512 MB，光数据库就 420 MB |
| ClawCloud Run | ? | `claw.cloud` 从你这里返回 503，连不上 |
| Cloudflare Workers + D1 | ✗ | 免费档每请求 10 ms CPU，而 4-gram 打分要几百毫秒 |
| Vercel / Netlify | ✗ | 只能静态 + 函数包体 250 MB 上限，且 `vercel.app` 从你这里 443 超时 |
| 花生壳 / NATAPP 等内网穿透 | ✓ 备选 | 免费档能给固定二级域名，但限速 1 Mbps、1 GB/月，还要实名。比方案 A 稳，比方案 A 麻烦 |

## 6. 这几个文件是什么

| 文件 | 作用 |
| --- | --- |
| `公网访问.bat` | 方案 A 的一键入口（口令也在这里改） |

| `deploy/requirements.txt` | 服务端依赖（只有 fastapi + uvicorn） |
| `deploy/pack_db.py` | 把 `queries.db` 整理/压缩成方便传输的副本 |
| `deploy/README.md` | 上面这些的技术版说明 |
