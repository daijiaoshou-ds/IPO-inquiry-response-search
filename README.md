# 问询回复检索

把一份问询函里的问题粘进来，找出**别的公司被问过的同款问题**，直接去看它们怎么答。

不是语义搜索，也不是 RAG —— 是**逐字级的字符匹配**。原因很简单：问询函里的问题，
差几个字意思就南辕北辙（"存货跌价准备计提是否充分" 和 "存货跌价准备转回是否合理"
在向量空间里很近，在监管逻辑里是两回事）。

---

## 它解决什么问题

写问询回复时最费时间的不是"想怎么答"，而是"**这道题别人答过没有、答成什么样**"。

问询函的问题高度模式化：同一类问题，几十家公司的措辞几乎一样。所以只要把历史问询函
拆成"最小问题单元"，用字符相似度去撞，就能把一个问题的**同题历史答案**一次性捞出来。

```
自家问询函的一个问题
        │
        ▼  4-gram 逐字匹配 + IDF 加权 + 覆盖度
   ┌─────────────────────────────────────┐
   │ 尚水智能 r1 问题12  0.838  ★ 全文逐字命中 │
   │ 高特电子 r1 问题12  0.812                 │
   │ 博科测试 r1 问题11  0.795                 │
   └─────────────────────────────────────┘
        │
        ▼
   点开就是对方回复里对应的那一页
```

## 快速开始

### 方式一：直接用现成的（推荐）

下载离线包（Windows 10/11），解压到桌面或 D 盘，双击 `启动.bat`，浏览器自动打开。

> 发布包见仓库的 Releases / 作者主页。首次启动会在本机建索引（约 6 秒），全程不联网。

### 方式二：从源码跑

```powershell
# 需要 Python 3.10+
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m src.server --open
```

浏览器打开 <http://127.0.0.1:8765>。

> 源码仓库**不带数据**（索引库几百 MB，不适合放 git）。没有 `data/queries.db` 时，
> 页面能打开但搜不出东西 —— 可以先看"自己构建索引"那一节。

### 自己构建索引

把问询函 PDF 按 `公司_r轮次.pdf` 命名放进 `问询函/`，然后：

```powershell
.\.venv\Scripts\python.exe -m src.build_db --db data/queries.db --rebuild --jobs 6
```

`src/pdfread.py` 负责把 PDF 还原成带页码的行，`src/extract.py` 负责切出"最小问题"。
支持两类文档：

- **问询函本身**（问题单独成文）；
- **问询与回复**（交易所只公开回复时，回复里通常把原问题整段抄了一遍，可以从回复里回溯）。

## 功能

- **整段粘贴**：把自家问询函里一整段贴进去，内部先拆成多个最小问题，再按「你的第①问 /
  第②问」分组展示，分组标题完整显示不截断。
- **板块 / 章节 / 轮次筛选**，改任一条件自动重搜。
- **落点面板**：把你的问题按「逐字命中 / 仅 2 字级 / 无对应」三档画出来，一眼看出
  哪几个要求库里没人提过。
- **所有**逐字重合片段都标黄（不只是最长那一段），附原文页码与提问主体。
- 点一下展开"这家公司这个问题的全部小问"。
- 浅色 / 深色主题跟随系统；左侧栏宽度可拖动，记在本地。

## 检索是怎么算分的

| 项 | 权重 | 说明 |
| --- | --- | --- |
| 4-gram IDF 加权余弦 | 0.70 | 用全库文档频率把"企业会计准则""是否符合"这类满库都是的短语自动降权 |
| 最长公共子串 / 短者长度 | 0.20 | 保证"逐字命中一整句"的一定排在前面 |
| 同问题号 | 0.05 | 同一编号的问题通常问的是同一件事 |
| 同章节 | 0.05 | 章节是弱先验 |

再加两条规则：

- **套话降权**（×0.55）："核查上述事项并发表明确意见"这类跨公司 100% 命中的模板句；
- **句内最优**：一个问题里往往只有一句是你真正想找的，取分句最高分而不是整段平均分。

候选集先用 FTS5 trigram 索引粗筛，再对候选算全分，最后按最长公共子串预算收敛。

## 目录

```
src/
  pdfread.py      PDF → 行（只做坐标还原，不依赖字体名）
  normalize.py    归一化（strict 保留数字 / loose 去数字 / core 去法规引用）+ 套话判定
  extract.py      问询函 → 最小问题（章节 / 问题节 / 小问 / 提问段）
  schema.sql      建表语句
  build_db.py     扫描目录 → 抽取 → 入库 → 建索引
  qc.py           入库质量自检（8 项）
  search.py       检索与排序
  server.py       FastAPI 服务（单页前端，无构建步骤）
  webui/index.html
deploy/           容器化部署 + Cloudflare 隧道
pack/             离线发布包生成器
docs/部署指南.md   怎么给同事用：本机 / 局域网 / 固定网址 / 服务器
```

## 数据说明

- 语料来自**沪深北交易所公开披露的审核问询函及其回复**。
- 本项目只做**解析与检索**，不包含任何抓取逻辑，也不随仓库分发原始 PDF 或索引库。
- 检索结果仅供学习与研究参考，**不构成审计意见、投资建议或任何形式的专业结论**；
  准确性、完整性以交易所原始披露文件为准。
- 如权利人认为本项目的处理方式不妥，请联系删除。
